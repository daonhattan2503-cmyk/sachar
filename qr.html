TẠO QR MÔ HÌNH

Một mã quét.
Mở đúng mô hình.

Đăng website lên GitHub Pages trước, sau đó tạo QR cho từng cảnh để chèn vào sách hoặc phiếu học tập.

Dán URL thư mục gốc của web, không dùng link trang repository github.com.

CHỈ CẦN LÀM MỘT LẦN

Từ thư mục đến QR dùng được

  1. Đưa các tệp lên repositoryindex.html, viewer.html và các thư mục assets, vendor, css, js, data phải cùng ở thư mục gốc.
  2. Bật GitHub PagesSettings → Pages → Deploy from a branch → main → / (root) → Save.
  3. Mở URL HTTPS được GitHub cấpDán URL đó vào ô phía trên. Mỗi QR sẽ mở một mô hình riêng.
  4. In thử và quét qua 4GKiểm tra đúng cảnh, thử nút AR trên điện thoại hỗ trợ rồi mới in hàng loạt.

Thay GLB sau này vẫn giữ được QR, miễn là tên miền, thư mục và ID cảnh không đổi.
